# GN-RS8 Pro - G-MScreen Pro

تطبيق احترافي للتحكم في رسيفر GN-RS8 MiniHD Plus مثل G-MScreen الأصلي

## المميزات
- ✅ ريموت كامل أبيض مثل الأصلي (POWER, MENU, OK, VOL, الألوان)
- ✅ اتصال حقيقي على 192.168.8.100:20000 مع AUTH Bind Code
- ✅ إضافة سيرفرات CCcam / Newcamd / IPTV من الهاتف

## معلومات الجهاز
- IP: 192.168.8.100
- Bind: 210503352505
- Serial: 210503352505*--1493
